🏛️ AgentEcom 4-Pillar Architecture

High-Throughput Autonomous Commerce Engine Decoupled Architecture

Pillar 1 /mcp

🔌 FastMCP Service

Official Model Context Protocol Server (v2024-11-05). Acts as the centralized tool registry, prompt hub, and database gateway.

  • 13 FastMCP Tools: Search, product lookup, stock check, cart, checkout, returns, shipment tracking.
  • 5 FastMCP Prompts: Versioned system prompts and specialized shopping advisor personas.
  • 5 FastMCP Resources: Database schema, policies, live categories, orders.
  • Transports: In-process memory, SSE stream (/mcp/sse), JSON-RPC 2.0 (/mcp/rpc), and stdio.
Pillar 2 agentecom/agent

🧠 Autonomous Agent Service

LangGraph StateGraph Autonomous Shopping Assistant. Bridges to FastMCP tools dynamically and orchestrates multi-turn reasoning.

  • LangGraph Pipeline: Agent Reasoning Node -> FastMCP Tool Node -> Telemetry Auditor.
  • Resilient Fallback Cascade: Groq -> Gemini -> OpenRouter -> Local Offline Planner.
  • Token Economy: Computes raw vs compressed tool tokens and reduction percentage.
  • Memory: Persistent short-term session context and cross-session customer persona.
Pillar 3 agentecom/api

⚙️ Backend Engine

High-throughput FastAPI application orchestrating data ingestion, cache layers, search workers, and external Shopify platforms.

  • Sub-0.1ms Caching: Surgical reverse-indexed caching keyed by SKU, Category, and Query.
  • Zero-Polling Webhooks: HMAC-verified Shopify webhooks for real-time cache invalidation.
  • Hybrid Search: BM25 Sparse Lexical + Dense MiniLM Vectors + Reciprocal Rank Fusion (RRF).
  • Isolated Checkout: Short-TTL (15 min) transient checkout tables preventing cart pollution.
Pillar 4 agentecom/web

🎨 Frontend & Storefront Widget

Modern responsive web client, live storefront chat, telemetry inspection dashboard, and drop-in embeddable Shopify widget.

  • Conversational UI: Streaming markdown, interactive product cards, and 1-click cart addition.
  • Shopify Permalinks: Direct pre-filled /cart/{variant_id}:{qty} checkout link generation.
  • Embeddable Widget: <script src="/widget.js"> floating widget for any Shopify store theme.
  • Telemetry Inspector: Live visibility into MCP tool calls, latency, tokens, and hit rates.
